# AI Job & Resume Platform

An AI-powered job and resume platform built using the **MERN stack**. The platform helps job seekers discover relevant jobs, analyze their resumes, identify skill gaps, and receive AI-powered job recommendations.

Recruiters can create and manage job postings, view applicants, and update application statuses.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/harman-kaur01/ai-job-resume-platform.git
```

```bash
cd ai-job-resume-platform
```

---

### 2. Install backend dependencies

```bash
cd server
npm install
```

---

### 3. Configure environment variables

Create a `.env` file inside the `server` folder.

```env
PORT=5000
JWT_SECRET=your_jwt_secret
OPENAI_API_KEY=your_openai_api_key
MONGODB_URI=your_mongodb_connection_string
```

Do not commit the `.env` file to GitHub.

---

### 4. Start the backend

Inside the `server` folder:

```bash
npm start
```

The backend runs on:

```text
http://localhost:5000
```

---

### 5. Install frontend dependencies

Open another terminal:

```bash
cd client
npm install
```

---

### 6. Start the frontend

```bash
npm run dev
```

The frontend runs on:

```text
http://localhost:5173
```

## 🔑 Authentication

The application uses **JWT-based authentication**.

After successful login:

* JWT token is generated by the backend.
* The frontend stores the token.
* Protected requests send the token using the `Authorization` header.
* Backend middleware verifies the token.
* Role-based middleware controls access to recruiter and job-seeker APIs.
